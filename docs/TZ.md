# Техническое задание ЛР1 «Деревья»

## Цель

Реализовать шаблонное бинарное дерево поиска на C++17. Поддержать обычное дерево и режим AVL. Узлами владеют std::unique_ptr. Для рабочих коллекций используются контейнеры из include/lab2_files.

|---|---|---:|
| 1 | Вставка, поиск, удаление | 5 |
| 1.1 | AVL-балансировка | 2 |
| 1.2 | Map, Reduce, Where | 3 |
| 1.3.2 | Прошивка по любому из шести обходов | 4 |
| 1.4.2 | Сохранение по строке формата | 3 |
| 1.5.2 | Чтение по строке формата | 4 |

| 7.2 | Интерфейс IEnumerable и TreeEnumerator | 3 |
| 7.3 | Перегруженные операторы | 2 |
| | **Итого** | **33** |

## Ввод и результат

Консоль позволяет выбрать int, double, string, Student или Teacher и один из двух режимов дерева. Данные можно вводить вручную, прочитать из строки или сгенерировать в случайном, возрастающем или убывающем порядке. При чтении и сохранении используется заданная пользователем строка формата. По умолчанию это {К}(Л)[П]. Без балансировки чтение восстанавливает форму, в режиме AVL допускается её изменение. Интерфейс показывает результаты операций, структуру и обход дерева.

Эквивалентные ключи хранятся один раз. Для вещественных ключей допустимы конечные значения. Ошибки формата, входных данных и индекса сообщаются пользователю. Успешные вставка и удаление сбрасывают прошивку.

## Проверка

Проверить дерево тестами GoogleTest. Сравнить обычное BST и AVL в Release, измеряя время на отсортированных, обратных и перемешанных данных. Сохранить замеры в CSV и построить графики для больших и очень больших объёмов. Для обычного BST на монотонном входе использовать отдельный предел из-за квадратичного роста времени построения.
